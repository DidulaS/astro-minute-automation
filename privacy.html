Privacy Policy

Astro Minute Automation

Last updated: October 29, 2026

1. Introduction

Astro Minute Automation is a personal application used by the Astro Minute YouTube channel owner to generate and upload educational space and science videos.

2. Google Account Access

The application uses Google OAuth 2.0 to obtain permission to upload videos to the authorized YouTube channel.

The application requests the YouTube upload permission. It does not request access to Gmail, Google Drive, or Google account passwords.

3. Information Used

The application processes video files, video titles, descriptions, and YouTube authorization credentials necessary for uploading content.

4. Storage and Security

OAuth credentials are stored locally by the channel owner and in GitHub Actions repository secrets for automated uploads.

Generated video files may be temporarily stored as GitHub Actions artifacts. The application does not intentionally publish authorization credentials.

5. Data Sharing

Upload information is sent to Google and YouTube to perform the requested video uploads.

The application also uses GitHub Actions and a third-party text-to-speech service to process generated video content.

6. Data Retention

Generated workflow artifacts are configured for seven-day retention. Authorization credentials remain stored until deleted, replaced, or revoked by the channel owner.

7. Revoking Access

The channel owner may revoke access at: Google Account Connections .

Stored credentials can also be deleted from the local computer and GitHub Actions repository secrets.

8. Contact

For questions concerning this application, contact: astrominute628@gmail.com
